# viaje-corea

PWA personal y offline para un viaje a Corea del Sur (HTML, CSS y JS puro, en GitHub Pages).

- Cómo se usa, cómo está hecha y cómo hacer otra igual para otro país: [GUIA-APP.md](GUIA-APP.md) (también dentro de la app: Más → 🛠️ Guía de la app).
- Reglas del proyecto: [CLAUDE.md](CLAUDE.md) · Diario de versiones: [PROGRESO.md](PROGRESO.md).
- Los datos privados del viaje (trip.json) no están en el repositorio: se importan en el móvil. Ejemplo ficticio: example.trip.json.
